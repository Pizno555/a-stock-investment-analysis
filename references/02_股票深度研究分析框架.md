# 02｜股票深度研究分析框架（MVP Candidate）

本文件定义“需要分析什么”。根据任务Lens选择必要模块；完整个股深研时原则上覆盖全部核心模块。

## 1. 研究快照与结论摘要
先列研究日期与关键数据截止时间，再用简短结论回答：
- 公司质量
- 核心逻辑与证据状态
- 业绩兑现程度
- 同行位置
- 市场预期
- 估值/股价位置
- 风险收益
- 关键推翻条件

## 2. 商业模式与产业链定位
分析核心业务、收入与利润来源、行业生命周期、价值链位置、当前市场关注业务的真实占比和商业化阶段。

产业链受益可用：核心受益 / 直接受益 / 业绩受益 / 弹性受益 / 间接受益 / 远期受益 / 产业链相关 / 概念映射 / 蹭热点。判定需与Reference 01的商业化阶梯和Decision-Critical Coverage一致。

## 3. 护城河与竞争优势
从技术/专利、客户认证与转换成本、规模/成本、产能/良率/交付、品牌/渠道/网络效应等适用维度判断；不适用的维度无需硬凑。若给1-10分，必须说明评分依据与主要扣分项，评分不是结论替代品。

## 4. 管理层与治理
关注管理层履历、资本配置、战略兑现、股权激励、关联交易、减持/质押、历史承诺与执行偏差。对管理层表述需区分“公司陈述”与“外部验证”。

## 5. 财务健康与盈利质量
近5年+最新季度按任务需要分析：
- 营收、扣非净利润、毛利率、净利率、ROE
- 经营现金流、自由现金流、利润现金含量
- 应收、存货、合同负债、Capex、在建工程
- 有息负债、流动性、利息保障
- 政府补助、投资收益、减值、商誉

重点回答增长来自需求、销量、价格、份额、产能、国产替代、并表、低基数还是一次性因素；利润是否转成现金。

## 6. 增长与业绩传导
建立：行业需求 → 价格/销量 → 订单 → 产能利用率 → 收入 → 毛利率 → 净利润 → 经营现金流。
说明每一环的证据状态、最早兑现时间和最脆弱环节。

TAM/SAM/SOM仅在有可靠口径时使用；不为完整感强行给市场空间数字。

## 7. 同行比较
先说明同行选择理由，再统一口径比较：业务结构、产品等级、客户、订单、产能、盈利、现金流、市占率、研发、估值、预期和股价位置。
最终回答谁更核心、谁更有弹性、谁兑现度更高、谁预期更充分。

## 8. 估值方法选择
默认参考：
- 稳定现金流：DCF + PE/EV
- 成熟盈利：PE / EV-EBITDA
- 金融：PB / ROE等适用框架
- 强周期：Normalized Earnings / PB / EV
- 亏损成长：PS / EV-Sales + unit economics
- 多业务集团：SOTP

可偏离但需说明原因。估值必须列关键口径、假设、敏感性和失效条件；不得因某单一倍数低就认定低估。

## 9. 市场预期与预期差
区分Reference 01定义的六类预期来源。回答：市场当前交易什么、哪些催化已price-in、哪些仍是未验证预期、何种结果才算真正超预期/低于预期。

## 10. 财报分析/财报预判
财报分析优先比较：营收、扣非净利润、EPS、毛利率、现金流、关键运营指标；Actual vs可验证预期；管理层指引；资产负债表和现金流质量；财报后股价与成交反应；如有可靠资料，跟踪分析师盈利预测/目标价的上调或下调。

财报预判必须写清假设，不得把模型预测写成市场一致预期。

## 11. 风险、反证与推翻条件
完整深研时按适用性扫描：宏观经济、行业竞争、政策/监管、财务、技术路线、客户/订单、扩产/产能、估值/市场预期等风险；不适用项无需硬凑，但不得静默遗漏明显相关风险。

重点列能够改变主判断的风险，而不是凑数量。至少回答：
- 当前判断最脆弱环节
- 什么数据说明需求/订单/客户/价格/业绩判断错误
- 什么情况需要降低评级或风险暴露
- 什么情况必须放弃投资逻辑

## 12. 情景分析
必要时设乐观/基准/悲观情景，明确需求、价格、订单、产能、利润率、估值等假设及失效条件。
概率只有在能说明依据时才使用；否则不给伪精确概率。

## 13. Research-to-Action结论
研究结论与交易系统分开。可根据证据、估值、预期和风险收益给出：观察 / 等待验证 / 轻仓试错 / 回调后评估 / 趋势持有 / 高位不追 / 降低风险暴露 / 放弃等研究层建议。

必须说明触发条件、继续成立条件和退出/推翻条件；需要时区分短期（事件/催化）、中期（业绩兑现/估值变化）和长期（竞争优势/增长假设）；不承诺收益。

## 14. 完整个股深研建议结构
完整研究时可按以下顺序组织，但可合并重复部分：
1. 研究快照与结论
2. 商业模式/产业链
3. 护城河与管理层
4. 财务健康
5. 增长与业绩传导
6. 同行比较
7. 估值
8. 市场预期
9. 财报/催化（如适用）
10. 风险、反证与情景
11. Research-to-Action

避免为了模板机械重复同一证据或结论。
