# a-stock-investment-analysis

`a-stock-investment-analysis` 是一个面向**全球上市股票**的完整投资研究 Skill，对中国 A 股启用更严格的证据核验与研究覆盖要求。

它的核心用途不是简单汇总新闻或财务数据，而是把：

**事实与证据 → 公司与产业分析 → 财务质量 → 盈利预测 → 估值 → 市场预期 / Price-in → 风险与反证 → 条件式投资判断**

连接成一套完整、可追溯、可证伪的股票研究流程。

---

## 1. 这个 Skill 能做什么

适合处理以下类型的问题：

- **完整个股深度研究**：商业模式、产业链位置、竞争优势、管理层、财务、增长、同行、估值、风险。
- **财报与 Guidance 分析**：判断业绩质量、增长来源、利润兑现、现金流以及未来指引是否支持当前预期。
- **盈利预测**：基于产能、销量、ASP、产品结构、市场份额、毛利率、费用率等经营变量建立 Forward Earnings。
- **情景分析**：构建 Base / Bull / Bear 情景，明确不同结论依赖哪些关键假设。
- **估值**：根据公司特征选择 PE、PB、EV、DCF、SOTP、Normalized Earnings 等方法，而不是机械套用统一估值模型。
- **周期股正常化估值**：区分当前高景气利润与可持续盈利，显式建立 Normalized Earnings。
- **市场预期与 Price-in**：分析市场已经在交易什么、当前股价隐含了什么增长和盈利要求。
- **同行比较**：比较业务结构、成长性、盈利质量、估值和竞争位置，并说明可比性的边界。
- **产业链、客户、订单和商业化研究**：核验公司是否真正受益，以及“产品、认证、订单、收入、利润”之间是否已经形成闭环。
- **消息与传闻核验**：追溯原始来源、判断证据强弱、寻找独立交叉验证和重大反证。
- **投资判断**：回答“现在值不值得买”“是否高估/低估”“还能不能参与”“什么情况下逻辑失效”等问题，并给出条件式 Research-to-Action 结论。

它尤其适合那些不能只靠一个财务指标、一个估值倍数或一条新闻就回答的问题。

## 2. 它会怎样分析一只股票

根据问题复杂度，Skill 会自动组合需要的研究步骤。完整研究通常包括：

1. **确认研究对象和时间截面**  
   明确公司、证券、上市市场、股价时间点、财务数据截止时间和新闻截止时间。

2. **核验证据**  
   优先使用公司公告、交易所、监管文件、财报、官方 IR、客户与产业链官方信息等高质量来源，并主动检查反证。

3. **分析商业模式与产业位置**  
   判断公司靠什么赚钱、真正受益于什么、竞争优势是否可持续，以及产业景气如何传导到公司收入和利润。

4. **检查财务质量**  
   分析收入、利润、现金流、应收、库存、资本开支、负债等，判断增长是否真实、利润是否真正转化为现金。

5. **建立盈利预测**  
   从可验证事实出发，把销量、价格、产品结构、市场份额、产能、毛利率等关键经营变量连接到未来收入、利润和现金流。

6. **构建 Base / Bull / Bear 情景**  
   将事实、管理层指引、市场一致预期和模型假设分开，说明不同情景为什么成立。

7. **进行估值**  
   根据企业性质选择适合的估值方法，并检查估值倍数、盈利口径、股本和估值时间点是否一致。

8. **分析市场预期与 Price-in**  
   判断当前价格已经反映了多少乐观预期，以及市场需要什么盈利结果才能支撑当前估值。

9. **寻找重大反证和失效条件**  
   主动回答：什么事实出现后，当前投资逻辑应该被削弱、推翻或重新评估？

10. **形成条件式投资判断**  
    将公司质量、逻辑真实性、业绩兑现、市场预期、估值、风险收益和推翻条件综合起来，给出研究层面的参与、等待、持有、降低风险或放弃条件。

简单问题不会机械输出完整十个章节，但后台研究标准不会因为问题很短而自动降低。

## 3. 怎么使用

在支持 Skill 的环境中加载或安装本 Skill 后，**直接用自然语言提问即可**。通常不需要告诉它应该读取哪个 Reference，也不需要手动指定研究流程。

### 最简单的用法

直接问：

> 新易盛现在值不值得买？

Skill 会根据这个问题自动判断需要进行证据核验、财务分析、盈利预测、估值、Price-in、风险与反证分析，而不是只根据当前 PE 或近期股价给结论。

### 想做完整深研

可以问：

> 深度研究新易盛。重点分析公司竞争力、800G/1.6T增长、客户与产能、未来两年盈利预测、估值、市场已经Price-in了什么，以及当前风险收益。

### 想研究财报

可以问：

> 分析 Broadcom 最新财报和 Guidance。判断 AI 业务增长是否超预期，增长能否持续，并重新评估未来盈利和当前估值。

### 想做财报预判

可以问：

> 预判中际旭创下一次财报。请从出货量、产品结构、ASP、毛利率、产能和客户需求建立 Base / Bull / Bear 盈利情景，并与市场预期比较。

### 想做周期股估值

可以问：

> 对洛阳钼业做周期股估值。不要直接拿当前利润乘 PE，请先建立铜、钴价格和产销量假设，计算 Normalized Earnings，再判断合理估值区间和当前股价隐含了什么。

### 想比较两家公司

可以问：

> 对比新易盛和中际旭创。不要只比较估值，重点比较业务结构、增长确定性、盈利弹性、市场预期、未来两年盈利和风险收益。

### 想核验产业链消息

可以问：

> 核验“某公司已经进入 NVIDIA 某产品供应链”这条消息。追溯最早来源，区分送样、认证、订单、量产和收入，并说明如果消息成立，对未来业绩的实际影响有多大。

### 只想要简短结论

也可以直接要求输出形式：

> 一句话告诉我新易盛现在值不值得参与，然后只列三个最关键理由和两个推翻条件。

Skill 会压缩最终输出，但不会因此降低后台证据核验和估值标准。

## 4. 怎样提问效果更好

Skill 可以处理很短的问题，但如果你有明确要求，最好直接告诉它。常用的附加条件包括：

- **研究截止时间**：例如“以 2026-09-30 收盘为截止时间”。
- **重点问题**：例如“重点看 1.6T、客户和毛利率”。
- **投资周期**：例如“按未来 12～24 个月研究”。
- **希望使用的情景**：例如“给 Base / Bull / Bear 三种情景”。
- **估值要求**：例如“同时看 Forward PE 和 reverse valuation”。
- **比较对象**：例如“与中际旭创、Coherent、Lumentum 对比”。
- **输出长度**：例如“完整研报”“控制在 1500 字”“只给核心结论”。
- **已有假设**：例如“假设明年 1.6T 出货达到某水平，重新计算盈利弹性”。

如果用户没有提供这些条件，Skill 会根据任务自行选择必要的研究深度和方法。

## 5. 输出通常包含什么

不同问题会输出不同结构。对于完整投资研究，通常会覆盖：

- 核心结论；
- 关键事实及证据强弱；
- 商业模式与产业链定位；
- 竞争优势与同行位置；
- 财务健康与盈利质量；
- 核心增长驱动；
- Forward Earnings / Base-Bull-Bear；
- 估值方法与合理价值区间；
- 市场一致预期与 Own Model 的差异；
- 当前价格已经 Price-in 什么；
- 主要风险和反证；
- 投资逻辑的失效条件；
- 条件式 Research-to-Action 结论。

对简单任务则会自动缩短，只保留与决策真正相关的部分。

## 6. A 股研究的特点

研究中国 A 股时，会额外强化证据覆盖和交叉验证，重点检查：

- 公司官方披露；
- 交易所与监管资料；
- 客户与订单；
- 技术、产品与认证；
- 产业景气；
- 财务与经营数据；
- 同行比较；
- 反证与风险；
- 研究与权威媒体；
- 市场讨论与预期。

其中市场讨论只作为发现线索和观察市场预期的辅助材料，不能替代事实证据。

## 7. 使用原则与边界

- **最新事实需要联网核验。** 股价、财报、公告、监管、客户、订单、行业数据和新闻等时效性信息不能只依赖模型记忆。
- **事实和预测必须分开。** 已确认事实、管理层 Guidance、市场 Consensus、模型假设和未确认信息不能混写。
- **相关不等于受益。** 产业链有关联，不代表一定能形成订单、收入和利润。
- **公司优秀不等于当前价格值得买。** 公司质量、盈利增长、市场预期和估值必须分别判断。
- **预测不是确定事实。** 盈利预测和估值结论依赖假设，应结合情景和敏感性理解。
- **不承诺收益。** 输出用于投资研究与决策支持，不构成收益保证或自动交易指令。
- **默认不使用固定技术交易体系。** 除非用户明确要求，否则不会自动加入 MA、MACD、RSI 等技术指标作为核心投资结论。

## 8. 核心方法文件

Skill 内部包含三份核心研究规范：

- `references/01_股票研究与证据验证方法论.md`：负责证据发现、核验、溯源、反证以及 Evidence → Earnings。
- `references/02_股票深度研究分析框架.md`：负责完整公司研究、财务、增长、同行、风险和 Research-to-Action。
- `references/03_预测、估值与预期差建模规范.md`：负责 Forecast、Normalized Earnings、Valuation、Consensus、Price-in 和情景建模。

正常使用时不需要手动调用这些文件；Skill 会根据问题自动决定需要使用哪些研究规范。

## 9. 一句话理解

> **给它一只股票或一个投资问题，它会先判断什么是真的，再判断公司能赚多少钱、市场已经预期了多少、当前价格是否合理，最后告诉你这个投资逻辑在什么条件下成立、什么条件下应该被推翻。**
